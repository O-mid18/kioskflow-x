## gstack skills

This project has gstack skills installed in `.claude/skills/`. Use them for all major workflows:

- `/review` — code review before shipping
- `/qa` — QA test a URL in a real browser
- `/ship` — create PR + push
- `/investigate` — root-cause a bug
- `/office-hours` — product/architecture planning
- `/cso` — security audit (OWASP + STRIDE)
- `/plan-eng-review` — engineering plan review
- `/plan-ceo-review` — CEO-level product review
- `/plan-design-review` — design review
- `/design-review` — UI/UX review
- `/autoplan` — auto-generate an implementation plan
- `/spec` — write a product spec
- `/retro` — retrospective
- `/careful` — extra-careful mode for risky changes
- `/canary` — canary deploy check
- `/health` — project health check
- `/learn` — explain a codebase area
- `/diagram` — generate architecture diagram
- `/document-release` — release notes
- `/devex-review` — developer experience review
- `/freeze` / `/unfreeze` — freeze/unfreeze a file from AI edits
- `/guard` — add guard rails to a file
- `/scrape` — scrape a URL
- `/land-and-deploy` — land + deploy a PR
